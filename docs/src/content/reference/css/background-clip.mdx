---
title: Background Clip
---

Restricts the area an element's background is painted in. Three of its values are boxes; the fourth is `text`, which cuts the background down to the element's own glyphs. Check out the [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/background-clip) for how to use.

<Sandpack>

```js
export default function App() {
  const [clip, setClip] = React.useState('text');

  return <>
    <button onClick={() => setClip(x => (x === 'text' ? 'border-box' : 'text'))}>
      background-clip: {clip}
    </button>

    <view className="headline" style={{ backgroundClip: clip }}>GRADIENT</view>
  </>;
}
```

```css active
.headline {
  width: 320px;
  height: 120px;
  margin-top: 16px;

  font-size: 72px;
  text-align: center;
  color: transparent;

  background-image: linear-gradient(120deg, gold, crimson 40%, deepskyblue);
  background-clip: text;
}
```

</Sandpack>

## Values {/*values*/}

`border-box`, `padding-box`, `content-box` and `text`.

A comma-separated list gives one value per background image layer, in the same order as [`background-image`](/reference/css/background-image), and repeats if it is shorter than the list of images. The [`background-color`](/reference/css/background-color) takes the last value in the list, as CSS has it:

```css
background-image: linear-gradient(gold, crimson), url(res:noise);
background-clip: text, border-box;
```

The [`background`](/reference/css/background-image) shorthand carries it too. CSS spells the clip and the painting origin with the same three box keywords there, so one box in a layer sets both and two set the origin first:

```css
background: linear-gradient(gold, crimson) text;
```

## Notes {/*notes*/}

- `text` clips the background and nothing else -- the glyphs are still painted over it in their own [`color`](/reference/css/color). Pair it with `color: transparent` for the gradient-text effect.
- Every glyph under the element counts, a child element's text included, and nothing else does: an element with no text and `background-clip: text` paints nothing at all.
- It clips whatever the layer is -- a gradient, an image, a [blended](/reference/css/background-blend-mode) layer, the background colour -- and leaves borders, [`box-shadow`](/reference/css/box-shadow) and [`mask-image`](/reference/css/mask-image) alone, as CSS does.
- The glyphs are rasterised into a coverage texture the size of the element, by a command buffer rather than a camera, and only when the text, its layout or that size changes. An element whose text is sitting still costs nothing per frame.
- The three box keywords are accepted and round-trip, but do not differ from each other yet: each one paints the area the background already covers, which stops at the padding edge. On an element with no border that is the border box as well, so the divergence only shows under one.
