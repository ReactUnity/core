---
title: CSS Rules
---

Everything a stylesheet can carry besides declarations: the at-rules that decide when a block of
rules applies, and the syntax that decides how rules are written and how they rank against each
other.

- [`@media`](/reference/rules/media-queries) applies a block when the screen, the player or the device matches
- [`@container`](/reference/rules/container-queries) applies a block when an ancestor's size or style matches
- [`@supports`](/reference/rules/feature-queries) applies a block only where ReactUnity has the property or value it names
- [`@layer`](/reference/rules/cascade-layers) orders groups of rules independently of how specific their selectors are
- [`@scope`](/reference/rules/scoped-styles) limits a block to one subtree
- [Nesting](/reference/rules/nesting) puts a rule inside another instead of repeating its selector
- [`@property`](/reference/rules/registered-properties) registers a custom property, so `var()` reading it has a value everywhere
