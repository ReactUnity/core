### `light-dark()` reaches Unity as written from a Vite build

The Vite preset names an old browser as the CSS target so Lightning CSS lowers `oklch()`,
`color-mix()` and nesting, which ReactUnity does not read. That target also lowered `light-dark()`,
into two variables only a `color-scheme` declaration in the same sheet defines — so an app's own
`light-dark()` colours came out invalid unless a Tailwind `scheme-*` utility happened to sit next to
them. The preset excludes that one feature from the lowering, since ReactUnity resolves
`light-dark()` itself. An app that sets `css.lightningcss.exclude` keeps its own value.
