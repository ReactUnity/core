### A minified `filter` is read as written

`filter: grayscale(1) brightness(0.85)` comes out of a CSS minifier as
`filter:grayscale()brightness(.85)` — the argument dropped because it is that function's default, and
the space dropped because `)` cannot run into an identifier. The parser split the value on
whitespace, so that was one token naming no function at all; it handed the token to the function
parser, got a null back, and read its length before checking it for null. The
`NullReferenceException` unwound through `StyleSheet.Parse`, so a single declaration cost the whole
sheet and the app rendered unstyled — which is what anyone building with Vite got, lightningcss being
its default CSS minifier.

`filter` is a list of function calls and is split as one now. A call ends at the `)` that closes it,
whether or not a space follows, and a nested `rgba()` inside a `drop-shadow()` does not end the call
around it. **An empty argument list is valid CSS** and means that function's own default, which is
where the minifier puts it: `grayscale()`, `invert()` and `sepia()` are the full effect, and
`blur()`, `brightness()`, `contrast()`, `saturate()`, `opacity()` and `hue-rotate()` are the
identity. A call naming a function ReactUnity does not have is skipped rather than failing the
declaration, so the rest of the list still applies.

`backdrop-filter` shares the parser and gets all of it.
