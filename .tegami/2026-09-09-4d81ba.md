### A minified `filter` no longer takes the stylesheet down with it

`filter: grayscale(1) brightness(0.85)` comes out of a CSS minifier as
`filter:grayscale()brightness(.85)` — the argument dropped because it is that function's default, and
the space dropped because `)` cannot run into an identifier. The parser split that on whitespace,
handed one token to the function parser, got a null back, and read its length before checking it for
null. The `NullReferenceException` unwound through `StyleSheet.Parse`, so a single declaration cost
the whole sheet and the app rendered unstyled.

The null is checked before it is read now, so the declaration is skipped rather than fatal. What is
still missing is the parse itself: several filter functions written without whitespace between them
are one token that names no single function, and `grayscale()` on its own means `grayscale(1)` rather
than nothing. Both are dropped for now.
