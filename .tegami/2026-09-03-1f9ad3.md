### Tailwind's Preflight, rewritten for ReactUnity

`@reactunity/renderer/tailwind.css` replaces Tailwind's Preflight, which resets elements ReactUnity
has not got while leaving ReactUnity's own control styling half undone. This resets what ReactUnity
renders instead: `button`, `input` and `toggle` lose their padding and grey fill so `p-*` and `bg-*`
are the only things that decide, `appearance` stays so they still behave as controls, and the root
gets a line height and the font family ReactUnity ships. It also carries `--font-sans` and
`--font-mono`, whose Tailwind defaults are stacks of web font names.

An app still writes the one line Tailwind's docs give it:

```css
@import "tailwindcss";
```

`@reactunity/renderer/vite` aliases that bare specifier to this file, and
`reactUnity({ tailwind: false })` turns the alias off. Either half can be imported alone, as
`@reactunity/renderer/tailwind/preflight.css` — into `layer(base)`, since an unlayered rule beats
every utility — and `@reactunity/renderer/tailwind/theme.css`.
[Using Tailwind CSS](https://reactunity.github.io/learn/howto/tailwind) covers what does and does
not carry over.
