### Selectors that were silently matching nothing

**`:only-child` works.** Its name was never registered, so it fell through to the custom-state path
and matched nothing. That path is now noisy: a pseudo-class ReactUnity does not know logs one
warning per name, saying it will only match while a state of that name is started on the element.

**`:not()` takes a list.** `:not(.a, .b)` used to be read as one selector, producing a class
literally named `a,`. Each branch is now negated on its own.

**`An+B` is read in full.** `:nth-child(2n-1)`, `:nth-child(-n+3)`, `:nth-child(n+2)` and a bare `n`
all resolve; only the plus-sign form did before, and the rest came out as a coefficient of zero.

**Pseudo-elements are not siblings.** A `::before` is a real child in the tree, so `:first-child`
used to fail on the first element of anything that had one. Every positional pseudo-class counts
real elements only.

**The `-of-type` family.** `:first-of-type`, `:last-of-type`, `:only-of-type`, `:nth-of-type()` and
`:nth-last-of-type()` count siblings of the same tag.

**Attribute operators.** `^=`, `$=`, `*=`, `~=` and `|=`, alongside the `=` and presence forms. A
value may be quoted with either quote or bare, and a trailing `i` compares case-insensitively. A
data prop set from JS as a number or a bool compares as its text, so `[data-index=6]` matches
`data-index={6}`. Combinators and spaces inside the brackets no longer break the selector apart.

**UIToolkit gets `:focus-within` and `:focus-visible`**, which UGUI has had. `:focus-visible` is on
when focus arrived by keyboard or gamepad navigation and off when a pointer put it there.
