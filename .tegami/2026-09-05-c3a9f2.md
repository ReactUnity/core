### Selectors that were silently matching nothing

**`:only-child` works.** It was parsed and had matching logic, but its name was never registered, so it fell through to the custom-state path and matched nothing. The same path is now noisy: a pseudo-class ReactUnity does not know logs one warning per name, saying that it will only match while a state of that name is started on the element — which is what `:hover` and a user's own states legitimately do.

**`:not()` takes a list.** `:not(.a, .b)` used to be read as one selector, producing a class literally named `a,`. Each branch is now negated on its own, so the rule matches what is neither.

**`An+B` is read in full.** `:nth-child(2n-1)`, `:nth-child(-n+3)`, `:nth-child(n+2)` and a bare `n` all resolve; only `An+B` with a plus sign did before, and the rest came out as a coefficient of zero. Whitespace inside the parentheses is fine either way. `:nth-child(2n of .x)` is still not read.

**Pseudo-elements are not siblings.** A `::before` is a real child in the tree, so `:first-child` used to fail on the first element of anything that had one, and `:nth-child()` counted from the wrong place. Every positional pseudo-class now counts real elements only.

**The `-of-type` family.** `:first-of-type`, `:last-of-type`, `:only-of-type`, `:nth-of-type()` and `:nth-last-of-type()` count siblings of the same tag.

**Attribute operators.** `[data-x^=v]`, `$=`, `*=`, `~=` and `|=`, alongside the `=` and presence forms that existed; a value may be quoted with either quote or bare, and a trailing `i` compares case-insensitively (`s` is accepted and is the default). A data prop set from JS as a number or a bool compares as its text — `[data-index=6]` matches `data-index={6}`. Combinator characters and spaces inside the brackets no longer break the selector apart.

**UIToolkit gets `:focus-within` and `:focus-visible`.** UGUI has had both; UIToolkit had only `:focus`. `:focus-within` follows the bubbling focus events, and `:focus-visible` is on when focus arrived by keyboard or gamepad navigation and off when a pointer put it there.
