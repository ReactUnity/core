### `:is()`, `:where()` and `:not()` take a complex selector anywhere

An argument that spans a combinator works in every position now, at the specificity of the most
specific argument, or none for `:where()`. Two forms used to match nothing: one whose compound does
not begin with the argument, which is `.dark\:x:where(.dark, .dark *)` — what Tailwind v4 emits for
the class-based dark variant its docs recommend — and one inside another functional pseudo-class,
such as `:not(:is(.a, .b))`. `:not(.a .b)` works too; it used to read `.a .b` as one class name with
a space in it.

### `:state(name)`

The standard spelling of a custom state. A bare unknown pseudo-class is still one — `:busy` matches
while a state named `busy` is started on the element — but it warns once about the name in case it
was a typo. `:state(busy)` says the state is meant, and does not warn.

### `::-webkit-scrollbar` and the other web spellings of the parts

`::-webkit-scrollbar`, `::-webkit-scrollbar-track`, `::-webkit-scrollbar-thumb`,
`::-webkit-input-placeholder`, `::-moz-placeholder`, `::-ms-input-placeholder` and `::-moz-selection`
name the same elements `::scrollbar`, `::scrollbar-thumb`, `::placeholder` and `::selection` do, so
a stylesheet written for a browser styles them without being rewritten.

### `@custom-media`

`@custom-media --name query;` names a media query list, or `true` or `false`, for use as a feature:
`@media (--name)`. A name is looked up when the query is evaluated, over every attached stylesheet,
so it can be declared in any sheet before or after its use and can come and go; the last declaration
wins. A pair of names that refer to each other is a cycle, and matches nothing.

### `@container scroll-state()`

`container-type: scroll-state` used to parse and decide nothing. `scroll-state(scrollable: edge)`
now reads such a container and holds while it can still scroll towards the edge — `top`, `bottom`,
`left`, `right`, their logical names, the `x`/`y`/`inline`/`block` axes, `none` for a container
scrolled as far as it goes in every direction, or bare `scrollable` for any edge. Features combine
with `and`, `or` and `not`. A change to the container's scrollable edges after layout restyles the
subtree; a position that only moves within the same edges restyles nothing.

`ContainerType` is a flags enum now, `ScrollState` alongside the size types, and the renderer's
`containerType` type accepts the combined spellings.

### `@supports selector()`

Answered instead of always false. One complex selector is supported when every part of it parses to
something this engine matches, every pseudo-class is known or a state the framework has a handler
for, and every pseudo-element is one some element has. A selector list, a relative selector,
`:popover-open` and `::marker` are not.
