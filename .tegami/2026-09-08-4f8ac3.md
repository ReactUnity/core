### `timeline-scope`

A timeline name is looked up from the animated element upwards, so a sibling of the scroll container
that declares it finds nothing — which is what a progress bar sitting next to a scroll view runs
into. `timeline-scope` on an ancestor of both lends the name to that ancestor's whole subtree, and
the timeline declared anywhere under it answers to the name everywhere inside.

```css
.reading { timeline-scope: --reader; }
.reading scroll { scroll-timeline: --reader; }
.reading .progress { animation-name: fill; animation-timeline: --reader; }
```

It takes one name, a comma-separated list of them, or `none`. Only one timeline may answer to a
scoped name: two elements declaring it under the scope, or none, both leave it inactive. The scope
claims the name either way, so the lookup stops there rather than carrying on to an outer
declaration.

`Scroll Animations` is a new page in the Kitchen Sink sample, covering this alongside
`animation-range` and per-element view timelines.
