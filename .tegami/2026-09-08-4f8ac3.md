### `timeline-scope`

A timeline name is looked up from the animated element upwards, so a sibling of the scroll container
that declares it finds nothing -- which is the case a progress bar sitting next to a scroll view runs
into every time. `timeline-scope` on an ancestor of both lends the name to that ancestor's whole
subtree, and the timeline declared anywhere under it answers to the name everywhere inside.

```css
.reading { timeline-scope: --reader; }
.reading scroll { scroll-timeline: --reader; }
.reading .progress { animation-name: fill; animation-timeline: --reader; }
```

It takes one name, a comma-separated list of them, or `none`. Only one timeline may answer to a
scoped name: two elements declaring it under the scope, or none, both leave it ambiguous and the
timeline inactive. The scope claims the name either way, so the lookup stops there rather than
carrying on to an outer declaration.

### A Kitchen Sink page for all of it

`Scroll Animations` is a new page in the sample: a scroll box whose progress drives a bar beside it
through `timeline-scope`, cards that animate over their own passage with a picker for the
`animation-range` they use, and a horizontal strip whose chips each name their own passage for the
label inside them to read.
