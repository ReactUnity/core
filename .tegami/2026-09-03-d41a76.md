### `@property`

`@property` registers a custom property and, above all, gives it an initial value — the value a
`var()` reading it gets where nothing has declared one. Without that, a declaration holding a
variable nothing has set is invalid and thrown away whole, which is why Tailwind v4's `shadow-*`,
`ring-*`, `translate-*`, `rotate-*` and gradient utilities all computed to nothing. All three
descriptors are read, a rule missing what it needs is ignored, and `inherits: false` stops an
ancestor's value reaching the element.

`syntax` is read but not enforced, so it only decides whether the rule needed an initial value at
all: with `syntax: "*"` and no `initial-value` the property is registered with no value, and a
`var()` reading it still falls through to its own fallback. An initial value comes ahead of that
fallback.

A registration belongs to the context rather than to the stylesheet it came from, so one sheet can
register what another reads, and removing that sheet withdraws it. `syntax` does not make a custom
property animatable, and a `@property` inside `@media` registers whether or not the query matches.
