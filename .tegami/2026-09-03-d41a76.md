### @property

**`@property` registers a custom property**, which above all gives it an initial value — the value a `var()` reading it gets where nothing has declared one. Without that, a declaration holding a variable nothing has set is invalid and thrown away whole, which is why Tailwind v4's `shadow-*`, `ring-*`, `translate-*`, `rotate-*` and gradient utilities all computed to nothing here: each sets one `--tw-*` and leaves the rest of the list to the initial values its `@property` rules declare. All three descriptors are read, a rule missing what it needs is ignored as a browser ignores it, and `inherits: false` means an ancestor's value does not reach the element — a custom property being inherited otherwise.

`syntax` is read but not enforced. The initial value is kept as written and converted where it is used, the way a declared variable's value is, so the descriptor only decides whether the rule needed one at all: with `syntax: "*"` and no `initial-value` the property is registered with no value, and a `var()` reading it still falls through to its own fallback — which is the other half of the pattern, as in `var(--tw-shadow-color, #0000001a)`. An initial value comes ahead of that fallback, a property that has one never being missing.

A registration belongs to the context rather than to the stylesheet it came from, so one sheet can register what another reads, and removing that sheet withdraws it. `syntax` does not make a custom property animatable, and a `@property` inside `@media` registers whether or not the query matches.
