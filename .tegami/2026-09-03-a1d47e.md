### A mounted `<style>` could be collected out from under its own updates

Toggling a `<style>` off — unmounting it, or setting `active={false}` — sometimes did nothing,
leaving the stylesheet applied for the rest of the session. No number of frames brought the update
through, because it never arrived: `<style>`, `<script>` and `<html>` are proxy components, which
nothing but a weak reference held once mounted, so a garbage collection between mounting one and
updating it discarded that command and every later one for the same element. A proxy component is
now held for as long as it is parented.
