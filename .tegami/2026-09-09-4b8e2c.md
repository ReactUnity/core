### A dev server can be restarted under a running app again

Vite's HMR client polls for a restarted dev server and reloads once it answers, and none of that
worked. Three pieces were missing.

`document` is an event target now — `addEventListener`, `removeEventListener` and `dispatchEvent` —
and reports `visibilityState` as `"visible"` with `hidden` false. Those two are constants on
purpose: the poll parks itself while the document is hidden, so driving them from Unity's focus
state would stall a restart for as long as the Editor sat in the background.

A `WebSocket` whose connection is refused reports `error` before `close`, as a browser does.
WebSocketSharp raises no error for a failed connect, only an abnormal close, so the ping that tests
whether the server is back waited forever.

And `EventTarget` dispatches over a copy of its handler list, so a handler that removes a listener
no longer throws `Collection was modified`.
