### `position: inset` is gone, and `absolute` does what it was for

`inset` was ReactUnity's own position value, added in 2022 because Yoga could not resolve insets
against a containing block that had padding. Yoga has rewritten absolute layout since, and
`absolute` is now correct on every case `inset` was carrying — it resolves against the padding box,
`inset: 0` fills it, `top: 0; bottom: 0` fills an axis, and an element with no insets sits at its
static position.

**`position: inset` is removed outright, not deprecated.** It is gone from the `PositionType` enum
and from the `Position` type in `@reactunity/renderer`, and nothing parses the keyword, so a
stylesheet that still declares it has an invalid declaration — which is dropped, leaving the element
at the `relative` default rather than taking it out of flow.

Search for `position: inset` and `'inset'` and change them to `absolute`. The only behaviour lost is
the over-constrained case: `inset` let a pair of insets override a declared `width` or `height`,
where CSS keeps the declared size. Drop the size — `height: initial` — to stretch.

The centred ripple in `@reactunity/material` was the only thing in the repo using it, and measures
identically under `absolute`.
