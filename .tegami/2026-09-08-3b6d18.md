### `position: inset` is gone, and `absolute` does what it was for

`inset` was ReactUnity's own position value, added the day after the Yoga 1.19 upgrade in June 2022
because Yoga could not resolve insets against a containing block that had padding. It sidestepped
layout entirely: instead of reading Yoga's computed position it drove the RectTransform's anchors
from the raw `top`/`right`/`bottom`/`left` values, which anchored the element to its containing
block's *border* box rather than its padding box.

Yoga rewrote absolute layout since, and `absolute` is now correct on every case `inset` was carrying.
Measured against a containing block that is border-box 200x160 with a 5px border and 20px of padding
— so its padding box is 190x150 at (5, 5) and its content box 150x110 at (25, 25):

| | `absolute` | `inset` |
|---|---|---|
| `inset: 0`, no width or height | fills the padding box | filled the border box |
| `top: 0; left: 0` | (5, 5) | (0, 0) |
| no insets | its static position, (25, 25) | (0, 0) |
| `top: 10%` | 10% of 150, so y = 20 | 10% of 160, so y = 16 |
| `bottom: 0`, `height: 32px` | y = 123 | y = 128 |
| `top: 0; bottom: 0`, `height: 32px` | height wins, as in CSS | insets won, stretching to 150 |
| `left: 20px; right: 20px`, no width | (25, 5), 150 wide | (20, 0), 160 wide |

So `top: 0; bottom: 0` fills an axis under `absolute` too, which is the one thing `inset` was still
advertised for. The only behaviour lost is the last row but one: `inset` let a pair of insets override
a declared `width` or `height`, where CSS treats that as over-constrained and keeps the declared size.
Drop the size — `height: initial` — to stretch.

`position: inset` still parses, as a deprecated alias for `absolute`, so an existing stylesheet keeps
rendering instead of silently falling back to `relative` on an unknown value. It is gone from the
`PositionType` enum and from the `Position` type in `@reactunity/renderer`.

The centred ripple in `@reactunity/material` was the only thing in the repo using it. It measures
identically under `absolute` — a padded, bordered button included, since insets never resolve against
padding — so the override is simply removed.
