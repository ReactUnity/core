### Structural pseudo-classes weigh as classes in the cascade

`:first-child`, `:last-child`, `:only-child`, `:nth-child()`, `:nth-last-child()`, the `-of-type` family, `:root`, `:scope` and `:state()` used to add a type selector's weight to a rule's specificity. They now add a class's weight, as every pseudo-class does on the web and as `:hover` and its kind already did here. The visible effect is on rules that tie otherwise: `text.item:first-child` now beats `.list .item`, where it used to lose. Pseudo-elements (`::before`, `::after`) keep a type selector's weight, which is also what the spec says.

A rule that relied on the old weight -- a structural pseudo-class losing to a second class -- resolves differently now. Add a class or restructure the selector where that matters.
