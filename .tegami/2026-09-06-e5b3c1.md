### Structural pseudo-classes weigh as classes in the cascade

`:first-child`, `:last-child`, `:only-child`, `:nth-child()`, `:nth-last-child()`, the `-of-type`
family, `:root`, `:scope` and `:state()` used to add a type selector's weight to a rule's
specificity. They now add a class's weight, as every pseudo-class does on the web and as `:hover`
already did here. Pseudo-elements keep a type selector's weight, which is also what the spec says.

Rules that tie otherwise resolve differently now: `text.item:first-child` beats `.list .item`, where
it used to lose. Add a class or restructure the selector where that matters.
