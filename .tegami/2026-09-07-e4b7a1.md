### `@scope`

`@scope (.card) to (.card-content) { image { … } }` styles the images under each `.card`, less those
inside its `.card-content`. Either prelude may be left out; without a start selector the root is the
stylesheet's scope element, or the document when it has none.

Inside the block a rule matches only elements in scope, root included, while the rest of its
selector reaches anywhere. `:scope` is the root at pseudo-class specificity, `&` is the root at
none, a relative selector such as `> .title` is anchored to it, and a declaration written directly
in the block styles the root. Outside any `@scope`, `:scope` with no scope element is now the root
element rather than nothing.

Scope proximity joins the cascade between specificity and source order: of two equally specific
declarations from different roots, the nearer root wins, and a scoped rule beats an unscoped one.
`@scope` nests inside style rules, where only its start selector resolves against the enclosing
rule, inside the conditional rules, and inside another `@scope`.
