### `background-blend-mode` actually blends

Every value but `normal` used to clear the background colour and hand it to the image as a tint, so
`multiply`, `hue` and `difference` all produced the same picture and none of them produced a blend.
Each background image layer now blends with what is under it, through the same sixteen functions
`mix-blend-mode` got, and the colour is painted underneath as well as being blended with. This
corrects the previous entry, which described `plus-lighter` on a background as tinting the image: it
adds the layer to what is under it, exactly as it does on `mix-blend-mode`.

The value is a **list**, one per background image layer in the order the images are given, repeating
when it is shorter than they are:

```css
background-image: url(res:noise), linear-gradient(gold, crimson);
background-blend-mode: overlay, normal;
```

The blend is weighted by what is underneath, as CSS specifies, so a layer with nothing behind it
comes through untouched.

**The bottom layer costs nothing extra**, which is almost every use: its backdrop is the background
colour, a value the shader is handed, so it is exact, free and identical under both render
pipelines. Only a layer above another has to read back what was painted, and that read is a
`GrabPass` on the built-in pipeline and the camera's opaque texture under URP — so **stacked
blending needs the built-in pipeline** while a single blended image works under both.

One consequence CSS does not have: an element that stacks blended layers becomes a blending group,
so a descendant's `mix-blend-mode` stops there. A single blended image does not do it.

**The useragent stylesheet had been leaning on the old behaviour.** A `toggle` drew its tick by
multiplying a white sprite against a black background colour, which under CSS's rules is a solid
black square over the whole control. The tick is a `mask-image` now, which is what that was reaching
for — the colour is what shows through the sprite, so it is recolourable, where before it was black
by construction.
