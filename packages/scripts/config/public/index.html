The previewer's Unity WebGL build is hosted rather than bundled, so the first load needs network access. It is cached by the browser afterwards.

To work offline, or to preview your own Unity scene instead, build a scene with a ReactRendererUGUI component and copy the output into a previewer folder in your React project, so that previewer/index.html exists. The dev server prefers that over this page.
