ReactUnity dev server

This server is running. It serves the JavaScript and asset files your ReactUnity app is built from, and reloads them as you edit.

Connecting Unity to it

Set the DevServer property of your ReactRendererUGUI or ReactRendererUIToolkit component to the address of this page, then press play.

Previewing in the browser

The previewer runs your UI in a Unity WebGL player right in the browser, with no editor open. Useful when starting out or for quick iteration on simple UI.

ReactUnity is not optimised for WebGL, so expect noticeably lower performance in the previewer than in a real player. It also has limited capabilities and will not handle every case.

The Unity build behind it is hosted on reactunity.github.io rather than shipped as a dependency, so nothing is downloaded at install time. The first load fetches it over the network and the browser caches it afterwards.

Using your own previewer

You can replace the previewer with your own scene — which is also how you preview offline. Build a scene in Unity with a ReactRendererUGUI component added, with its Type set to Url and Source Path set to /index.js. Then copy the build output into a previewer folder in your React project, so that this file exists: 

previewer/index.html

The dev server serves that in preference to the hosted previewer. Your project's own public folder takes precedence over both.

See the @reactunity/scripts documentation for the environment variables that control the build.
